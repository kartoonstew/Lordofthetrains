# Reference photos

All from Wikimedia Commons, saved at 1920 px wide for personal modelling reference.
Every photo shows the permanent Hobbiton Movie Set at Matamata, New Zealand (rebuilt for
*The Hobbit*, 2011), except 11, which shows the earlier, simpler set.
