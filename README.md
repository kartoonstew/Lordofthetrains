# HO Movie Scenery

3D-printable film landmarks, mostly Middle-earth, for an HO scale (1:87) train layout.
Bag End is built by Python scripts in Blender. OpenSCAD helpers are kept in `lib/` for
simpler pieces. Renders and photo-vs-model comparison sheets are generated from the scripts.

## Scale cheat sheet (HO, 1:87)

| Real world | Model |
|---|---|
| 1 m | 11.5 mm |
| 1 ft | 3.5 mm |
| Person, 1.75 m | 20 mm |
| Hobbit, 3'6" | 12 mm |
| Gandalf, hat included | ~23 mm |
| Track gauge | 16.5 mm |

**Selective compression.** Keep the parts people touch (doors, windows, fences, steps) at
true scale and shrink the landscape around them. Big landmarks (Orthanc would be over a
metre and a half tall at true HO) need heavy compression, or a half-relief version against
the backdrop.

## Layout

```
lib/ho.scad                 OpenSCAD: scale constants; preview-only figures and track
lib/terrain.scad            OpenSCAD: heightfield hills and shaping functions
lotr/shire/bag_end/         Bag End (see its README):
    blender/                  the Python package, build.py and the tests
    refs/                     credited reference photos
    renders/                  renders and photo-vs-render comparison sheets
    old_openscad/             the archived OpenSCAD attempt
    bag_end.blend             generated by the build
tools/blender.sh            run a Python script in headless Blender (5.0+, or set BLENDER=...)
tools/build_bag_end.sh      build Bag End: the .blend, renders and comparison sheets
tools/build.sh              build OpenSCAD models (none exist now, so it prints a message)
tools/estimate.sh           slice an STL with the Centauri Carbon profiles, report time and grams
tools/orca_flatten.py       helper for estimate.sh (Orca's CLI doesn't follow profile inheritance)
tools/side_by_side.py       reference photo next to a render, for checking proportions
```

Tests: `lotr/shire/bag_end/blender/tests/run_tests.py`, run through `tools/blender.sh`.

## Workflow

You need Blender 5.0 or newer at `/Applications/Blender.app/Contents/MacOS/Blender`. If it's
somewhere else, set `BLENDER=/path/to/Blender` when you run the tools.

1. Collect reference photos into the model's `refs/` folder, crediting each one in
   `refs/ATTRIBUTION.md`, and measure proportions from them.
2. Put the measurements into `lotr/shire/bag_end/blender/bagend/layout.py`, which holds the
   positions and sizes in metres.
3. Run the tests:
   `tools/blender.sh lotr/shire/bag_end/blender/tests/run_tests.py`
   (add a module name such as `test_layout` to run just that one).
4. Run the build: `tools/build_bag_end.sh` (add `--no-render` to skip the renders and comparison sheets).
   It writes `bag_end.blend` and the renders.
5. Open the comparison sheets in `lotr/shire/bag_end/renders/` (`compare_*.png`, photo on the
   left, render on the right) and check the proportions against the photo. If something is off,
   go back to step 2.

Once a model exports STLs, `tools/estimate.sh 0.2 path/to/model.stl` gives print time and
filament (use `0.4` for the 0.4 nozzle profile). Bag End doesn't export STLs yet.

For a simple piece that doesn't need Blender, write it in OpenSCAD with `lib/ho.scad` and
`lib/terrain.scad`, then add `stl` and `png` calls for it at the bottom of `tools/build.sh`.

## Ideas

Pieces the train can interact with:

- **Moria west-gate as a tunnel portal.** The Doors of Durin around a tunnel mouth; glow-in-the-dark filament for the Ithildin.
- **Brandywine Bridge** as a road or track bridge at the edge of the Shire.
- **Isengard's ring wall** around a loop of track, with a compressed Orthanc in the middle.
- **Argonath** flanking the line as a gateway (heavily compressed).
- **Bree west-gate** at a level crossing.

Set pieces: the Green Dragon, the Mill and Bywater bridge, the Party Tree, more hobbit holes
(cheap variations of Bag End), Weathertop, Edoras, and half-relief backdrops for Barad-dûr,
Minas Tirith and Rivendell.

From other films: the Glenfinnan Viaduct (the Hogwarts Express bridge, and a real railway viaduct)
and the Hill Valley clock tower.
